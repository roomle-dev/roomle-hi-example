# Images

Images referenced by backlog items, analysis documents, and context documents. Screenshots, diagrams, render outputs.

## Guidelines

- Image files (PNG, JPG, SVG) with descriptive kebab-case names.
- Images are referenced from markdown documents with relative paths.
- No generated build artifacts. Temporary screenshots go in `.temp/`.
- Images are kept as long as the document that references them exists.
